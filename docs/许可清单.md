# 原文许可清单

> 读者：想把本库内容再分发、或想公开全文翻译的人
> 结论先说：**20 篇里只有 4 篇可以公开发布全文翻译**
> 最后核对：2026-08-31

## 0. 先破一个误解

**「不能翻译」是误读。** 受限的是「公开再分发翻译」，不是「翻译」本身。

| 用途 | 受不受限 |
| --- | --- |
| 译成中文自己读、存本地、团队内部传阅 | 不受限，20 篇都可以 |
| 把全文翻译放进 public 仓库供人下载 | 受限，见下表 |
| 本库的**解读笔记** | 不受限。解读是原创评述，不是原文的演绎作品 |

arXiv 的默认许可叫「永久非独占许可」：作者把**分发权**授给 arXiv，但没有把
**再分发权和演绎权**授给第三方。翻译在著作权上属于演绎作品，所以公开发布需要授权。

⚠️ 本页是按各篇许可条款字面读法给的实操判断，**不是法律意见**。真要公开发布请自行复核。
想公开某一篇，最直接的办法是发邮件问作者——学术圈这类请求通过率很高。

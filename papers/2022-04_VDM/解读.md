# 大白话深读《VDM》

## 1. 30 秒定位

这篇论文解决的是“如何用扩散模型生成时间上连贯的高质量视频”。它把标准图像扩散模型的 U-Net 改成空间时间分解的 3D U-Net，并用同一个模型联合训练图像与视频，以减少小批量梯度方差、加速优化。为了生成更长、更高分辨率视频，论文提出重建引导采样（reconstruction-guided sampling），在采样时加入对已知帧重建误差的梯度项。代价是必须固定帧块训练、扩散采样需要多步迭代，而且长视频扩展需要额外反向传播。工作覆盖无条件生成、视频预测和文本条件生成，并在 UCF101、BAIR Robot Pushing、Kinetics-600 上报告了较优指标。

## 2. 为什么这篇论文会出现

扩散模型在图像、音频生成上已经取得高质量结果，但视频生成仍被 GAN、自回归模型、VAE 等主导。视频的难点在于高维张量和时间一致性：多帧输入会迅速超出深度学习加速器内存，模型必须学会帧与帧之间的连续运动，而不能只生成若干独立画面。

论文的出发点是：扩散模型的形式化几乎不用改，只需把图像架构自然扩展到视频。为实现这一目标，作者没有设计全新生成框架，而是采用 3D U-Net，并把空间和时间注意力分解开，以控制计算和显存。更关键的是，这种结构允许论文通过屏蔽时间注意力，让同一模型能同时接收独立图像帧；实验表明联合训练图像和视频目标明显提高样本质量。

另一个动因来自长视频生成。如果只在 16 帧小段上训练，测试时需要把短段扩展成长视频，常见替换采样法（replacement method）在已知帧和生成块之间会产生不连贯。论文发现替换法缺少条件期望中的一个修正项，因此提出重建引导采样来补足这一点。这样，无需单独训练条件模型，也能从无条件扩散模型中近似条件采样，完成长视频扩展、时间插帧和空间超分辨率。

## 3. 方法全景：先看数据流

先看整体数据流：

```text
训练
视频块 x: (T, H, W, C)
  |
  | 前向加噪 zt ~ N(zt; αt x, σt²I)
  v
zt, 条件 c, log SNR λt
  |
  | 3D U-Net（空间-时间分解）
  v
去噪输出 εθ 或 x̂θ
  |
  | 对 εθ 做 MSE / v 损失
```

```text
长视频/高分辨率采样
已有低帧率或低分辨率块 xa
  |
  | 作为重建目标
  v
各采样步：zt -> x̂θ(zt)
  |
  | 对未知块 latent 计算负梯度：- wr αt/2 ∇ ∥xa - x̂aθ(zt)∥²
  v
修正后的 x̃θ 用于更新下一步 latent
```

模型主体是 3D U-Net。输入是带噪视频 `zt`，形状为帧数×高×宽×通道；条件 `c` 可以是文本 BERT-large 嵌入，也可以为空；`λt` 是当前扩散时间的对数信噪比。输出是与输入同结构的去噪预测。

空间路径上，论文把图像 U-Net 的每个 2D 卷积改成空间-only 3D 卷积，例如 3×3 卷积变成 1×3×3 卷积。第一维索引视频帧，后两维索引高和宽。这样每个卷积只在一个帧内提取空间特征。每个卷积残差块后接空间注意力块，帧轴被当作 batch 轴处理，说明空间注意力不会混合不同时间帧。

时间路径上，每个空间注意力块之后插入时间注意力块。时间注意力在第一维——帧轴——上做注意力，空间高和宽被当作 batch 轴。也就是说，同一空间位置在不同帧之间被对齐建模。时间注意力块使用相对位置嵌入，让网络知道帧顺序，但不需要绝对时间概念。具体通道数和下采样块数在图 1 中标注，正文没有复述具体数值。

联合图像视频训练的关键是屏蔽时间注意力。训练时，论文从数据集中随机取独立图像帧拼到视频段末尾；对视频段各帧保持时间注意力，对每个独立图像帧则让注意力矩阵只匹配它自己，不与其他帧混合。这样模型既能学视频动态，也能学单帧图像生成。

重建引导采样不是额外训练一个条件模型，而是从无条件模型 `x̂θ` 派生条件修正。已知块 `xa` 可以是前序视频块、低帧率帧或低分辨率真值。对于待生成块 `xb`，论文不直接使用 `x̂bθ(zt)`，而是减去一个由 `xa` 的重建误差对 `zb` 的梯度项。该梯度项把已知块的重建质量作为引导信号，改善未知块的生成。

## 4. 核心公式与直觉

第一个必须理解的是前向扩散过程，原文 Eq. (1)：

\[
q(z_t|x)=\mathcal{N}(z_t;\alpha_t x,\sigma_t^2 I)
\]

其中 `x` 是原始视频张量，`z_t` 是时间 `t` 的带噪 latent，`α_t` 和 `σ_t` 是噪声调度参数。`λ_t=log(α_t²/σ_t²)` 表示对数信噪比，随时间 `t` 下降，直到 `t=1` 时接近标准高斯。这个式子说明视频不是一次性被破坏，而是按连续时间被逐步加噪；反向生成就是学习从噪声恢复出视频。

第二个关键式子是分类器无关引导，Eq. (6)：

\[
\tilde{\epsilon}_\theta(z_t,c)=(1+w)\epsilon_\theta(z_t,c)-w\epsilon_\theta(z_t)
\]

其中 `εθ(zt,c)` 是条件模型预测，`εθ(zt)` 是无条件模型预测，`w` 是引导强度。无条件模型可以通过让条件嵌入为零联合训练得到。这个式子通过放大条件预测偏离无条件预测的程度，令采样更忠实于条件，但会降低多样性并可能让 FID 类指标恶化。直觉是：它把生成过程推向隐式分类器认为条件出现概率高的区域。

第三个是论文新提出的重建引导采样，Eq. (7)：

\[
\tilde{x}^b_\theta(z_t)=\hat{x}^b_\theta(z_t)-\frac{w_r\alpha_t}{2}\nabla_{z^b_t}\|x_a-\hat{x}^a_\theta(z_t)\|_2^2
\]

这里 `x̂bθ(zt)` 是模型对未生成块 `xb` 的去噪估计，`x̂aθ(zt)` 是对已知块 `xa` 的重建，`wr` 是重建引导权重。梯度只对未知块 latent `zb_t` 求。该式来自对条件期望 \(E_q[x_b|z_t,x_a]\) 的近似：替换法只更新 `zb` 却没有修正 \(x_a\) 带来的条件信息，而重建引导用 `xa` 的重建误差补上类似“评分函数修正”的项。工程上，这意味着采样时每一步都要对已知帧计算 MSE，并反向传播到未知帧 latent，属于额外计算。

原文 Eq. (4) 中出现 `q(...)`，可能是 PDF 抽取时平方根符号丢失；本文不展开该式判断，仅说明祖先采样器包含该项。

## 5. 训练与推理怎么跑

**一轮训练 step**。从数据集中取若干帧组成的视频块，例如 16 帧、空间 64×64。若启用联合训练，再拼接 0、4 或 8 张随机独立图像帧。对每个输入加噪得到 `zt`；同时准备条件 `c`：无条件任务令 `c` 为空，文本任务使用 BERT-large 嵌入并经过注意力池化。时间 `t` 被采样，与 `c` 一起通过 MLP 嵌入后注入残差块。模型输出噪声预测 `εθ` 或 v 预测，然后计算 MSE 损失。训练会更新整个 3D U-Net 的参数；论文未明确披露 BERT-large 是否冻结、优化器、学习率或 batch size，这些在附录 A，原文正文未复述。联合训练时，时间注意力 mask 使视频帧之间互相注意，而独立图像帧之间不混合。

**完整推理顺序**。首先生成固定帧块，从 `z1 ~ N(0,I)` 开始，按离散时间步从 1 到 0 迭代。可选祖先采样器或预测器-校正器；后者在祖先步后加一步 Langevin 修正，采样步长为 0.1。文本条件模型使用分类器无关引导。为了生成 64 帧长视频，先用 16 帧模型生成前 16 帧，再以后续外推方式逐块生成；每一块的条件采样使用重建引导。低帧率到高帧率、低分辨率到高分辨率也使用相同方式：把低帧率或低分辨率真值视作 `xa`，高分辨率模型预测的下采样结果与 `xa` 比较，梯度更新高分辨率 latent。推理时模型权重保持冻结，重建引导的梯度只用于更新当前 latent，不更新模型参数。

## 6. 实验和消融证明了什么

| 证据 | 任务 / 数据集 | 关键指标变化 | 论文支持的含义 |
|---|---|---|---|
| Table 1 | UCF101 无条件视频生成 | 本文 FID=295±3、IS=57±0.62；TGAN-v2 在 64×64 为 FID=3431±19、IS=26.60±0.47；real data IS≈60.2 | 无条件生成质量明显优于所列基线，IS 接近真实数据。 |
| Table 2 | BAIR Robot Pushing 视频预测 | 本文 FVD=66.92（Langevin 256 步）；FitVid=93.6、VideoGPT=103.3 | 无条件训练加重建引导可适配视频预测，指标优于 GAN/VQ-VAE 基线。 |
| Table 3 | Kinetics-600 视频预测 | 本文 FVD=16.2±0.34；TrIVD-GAN-FP=25.74±0.66 | 在大规模动作数据集上显著改善 FVD，但作者也提示评测协议存在细节差异。 |
| Table 4 | 文本条件 16×64×64 联合训练 | 8 张图像帧时 FVD 从 202.28 降到 57.84；FID-avg 从 37.52 降到 15.57 | 联合图像视频训练是关键：图像帧越多，视频和图像质量都提升。 |
| Table 6 | 长视频自回归扩展 64×64×64 | 重建引导 FVD=136.22；replacement FVD=451.45 | 重建引导是长视频一致性最重要的消融，替换法会产生明显不连贯。 |

最关键的消融是 Table 6 的重建引导对比替换法，因为它直接验证论文为解决长视频扩展不连贯而提出的方法。Table 4 说明联合图像训练对样本质量的重要提升，也是决定模型训练策略的关键证据。

但有些主张尚未被实验完全证明。论文称在多个基准上达到 state-of-the-art，但这些数字来自不同文献的预处理和评测协议并不一致，Table 1 中不同方法分辨率也不同。长视频的“时间一致性”只在 FVD/FID/IS 等分布指标上体现，没有人类主观评价，也没有物理合理性测试。论文未披露模型参数量、训练算力、推理延迟，因此无法判断相对成本和可扩展性上限。

## 7. 与前作怎么选

对比对象取自论文列出的基线 VideoGPT、TrIVD-GAN-FP 和 FitVid。

| 方案 | 生成机制 | 论文报告的水平 | 何时选它 |
|---|---|---|---|
| VideoGPT | 自回归 + VQ-VAE | BAIR FVD≈103.3；UCF101 FID≈24.69 | 需要离散 token 或更轻量视频预测时可能合适，但本文未对比采样速度。 |
| TrIVD-GAN-FP | GAN 类 | Kinetics-600 FVD≈25.74、IS≈12.54 | 若已有成熟 GAN 训练流程、需单步生成，可考虑；但本文未披露其稳定性。 |
| FitVid | 视频预测模型 | BAIR FVD≈93.6 | 在明确条件预测且需要长期循环基线上可比较。 |
| VDM | 扩散 3D U-Net + 重建引导 | BAIR FVD≈66.92；Kinetics-600 FVD≈16.2 | 需要覆盖无条件、文本条件、视频预测多任务，且能接受多步采样时选它。 |

从论文给出的指标看，VDM 在多个任务上更优，但论文没有给出与这些强基线在同一硬件、同一推理步数预算下的延迟对比，所以不能仅凭 FVD/FID 判断部署选择。若应用要求低推理延迟、单步生成，VDM 的扩散采样可能不是最合适；若核心目标是分布覆盖和多功能条件生成，VDM 更有吸引力。

## 8. 工程判断与收束

数据层面，论文使用的 UCF101 有 13,320 个视频，块大小为 16 帧、64×64；BAIR Robot Pushing 约 44,000 个 64×64 视频；Kinetics-600 约 40 万训练视频；文本条件实验使用 10 万个？不，正文写“10 million captioned videos”，即 1000 万段带字幕视频。训练数据的清洗、过滤和文本来源在正文未详述。论文未披露 GPU 数量、训练时长、batch size、优化器、模型参数量，这些均在附录 A，正文无法核验。

算力和延迟方面，采样需要 128 到 512 个扩散步，重建引导还会增加每一步的反向传播计算。对于长视频自回归扩展，块与块之间顺序生成会使时延线性累积。实现难点在于：空间时间分解注意力中，帧轴和空间轴在 batch/attention 维度的语义切换需要仔细实现；联合训练时要对独立图像帧做精细 mask；重建引导要求采样时保持计算图以对 latent 求梯度。

最可能失败的环节是长时间自回归扩展中误差累积，尤其是遮挡、相机运动或动作突变时，重建引导可能过度约束已知块或无法正确传播条件。另一个风险来自文本条件训练数据的社会偏见，论文也承认目前没有做偏差审计。指标上限方面，FVD/FID/IS 只能反映分布和帧级质量，不能证明动作在物理上合理；当前实验主要覆盖 64×64、128×128 分辨率，更高分辨率和更长时序仍是开放问题。

读完必须记住的 5 件事：

1. VDM 用空间-时间分解的 3D U-Net，将标准图像扩散架构自然扩展到视频。
2. 联合训练图像和视频目标，通过时间注意力 mask 实现，实验表明能显著降低 FVD。
3. 重建引导采样不必单独训练条件模型，而是在采样时对已知帧重建误差求梯度。
4. 在 UCF101、BAIR、Kinetics-600 上的指标优于论文所列基线，但延迟和算力未披露。
5. 论文没有发布模型，长视频因果一致性、社会偏见和更高分辨率仍是未解决问题。

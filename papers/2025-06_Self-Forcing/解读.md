# 大白话深读《Self Forcing》

## 1. 30 秒定位

Self Forcing 是 Adobe Research 与 UT Austin 提出的自回归视频扩散模型后训练范式，论文发表于 NeurIPS 2025 (Spotlight)。它要解决的核心问题是曝光偏差（exposure bias）：模型训练时用真实历史帧当条件，推理时却只能用自己生成的不完美历史帧，误差会随序列变长不断累积。Self Forcing 在训练中直接执行自回归自展开（self-rollout），用模型自己刚生成的帧作为后续帧的条件，并在完整生成视频上做整体分布匹配损失。为了压低训练成本，作者使用少步扩散模型、随机梯度截断和滚动 KV 缓存。实验以 Wan2.1-T2V-1.3B 为基座，在单张 H100 上达到 17 FPS、0.69 秒首帧延迟，VBench 总分 84.31，与更慢的双向扩散模型 Wan2.1 相当，并优于 CausVid 等自回归基线。

## 2. 为什么这篇论文会出现

现代视频扩散模型通常采用双向注意力，一次性去噪全部帧。这种设计让未来帧可以影响过去帧，因此无法用于实时流式生成，首帧延迟也较高。自回归视频模型按时间顺序生成，天然适合交互式内容、游戏模拟和机器人学习，但传统自回归模型依赖有损向量量化，视觉保真度往往不如扩散模型。

为了结合两者，出现了两种主流训练方式：教师强制（Teacher Forcing, TF）和扩散强制（Diffusion Forcing, DF）。TF 用干净的真实历史帧作为条件，训练当前帧去噪；DF 让每帧拥有独立采样的噪声水平，用带噪声的真实历史帧作为条件。它们在训练时可以并行计算，但都面临一个关键问题：训练阶段看到的上下文分布与推理时模型自己产生的上下文分布不一致。推理时一旦前置帧出现瑕疵，后续帧会因为训练中从未见过这类输入而持续放大误差，表现为颜色过度饱和、过度锐化或随时间崩坏。CausVid 曾尝试把 DF 输出与 DMD 结合，但论文指出它优化的仍是 DF 训练分布，不是推理时的真实模型分布，因此匹配了“错误的分布”。

Self Forcing 受到早期 RNN 序列建模和 GAN 原理启发：生成器训练与推理应走同一条路径。作者没有继续在“如何注入噪声上下文”上打补丁，而是把自回归 rollout 搬进后训练阶段，让模型持续看到自己的错误，再用视频级分布匹配损失直接优化整条生成序列。

## 3. 方法全景：先看数据流

Self Forcing 的训练和推理都围绕同一个核心：用一个因果扩散 Transformer（Causal DiT）逐帧/逐块去噪，当前帧只依赖于过去已生成帧的 KV 缓存。

**训练数据流（单次 step）**

```
采样序列长度 N，去噪步数 T，随机采样 s ∈ {1..T}
初始化 Xθ = []，KV = []
for i = 1..N:
    x_i^{t_T} ~ N(0, I)                       # 当前帧从纯噪声开始
    for j = T..s:
        if j == s:                            # 只有最后一步开梯度
            grad ON
            x̂_i^0 = Gθ(x_i^{t_j}; t_j, KV)   # 因果 DiT 预测干净帧
            Xθ.append(x̂_i^0)                 # 收集完整生成视频
            grad OFF
            kvi = GKVθ(x̂_i^0; 0, KV)         # 从输出帧提取 KV 嵌入
            KV.append(kvi)                    # 缓存为未来帧的条件
        else:                                 # 其他去噪步不开梯度
            grad OFF
            x̂_i^0 = Gθ(x_i^{t_j}; t_j, KV)
            sample ε ~ N(0, I)
            x_i^{t_{j-1}} = Ψ(x̂_i^0, ε, t_{j-1})   # 注入更低噪声
对 Xθ 计算视频级分布匹配损失，更新 θ
```

**推理数据流（rolling KV cache）**

```
给定要生成帧数 M，缓存长度为 L
初始化 KV = []
for i = 1..M:
    x_i^{t_T} ~ N(0, I)
    for j = T..1:
        x̂_i^0 = Gθ(x_i^{t_j}; t_j, KV)
        if j == 1:                       # 最终干净输出
            Xθ.append(x̂_i^0)
            kvi = GKVθ(x̂_i^0; 0, KV)
            if |KV| == L: KV.pop(0)      # 移除最旧帧缓存
            KV.append(kvi)
        else:
            sample ε ~ N(0, I)
            x_i^{t_{j-1}} = Ψ(x̂_i^0, ε, t_{j-1})
```

核心组件拆解如下：

- **Gθ（因果 DiT）**：在因果 3D VAE 的潜在空间工作。输入当前帧/块的噪声 token 与过去帧的 KV 嵌入，输出预测干净 latent；GKVθ 额外返回当前输出帧的 KV 嵌入。注意力是因果的，因此可像语言模型一样缓存。

- **KV 缓存**：保存自生成历史帧的 clean key/value。训练时把流入缓存的历史帧梯度切断（detach），避免反向传播穿过整个 rollout 导致显存爆炸；推理时用滚动缓存支持长视频外推。

- **少步扩散**：用 4 步去噪近似每帧条件分布 pθ(xi|x<i)。这使自展开训练可行，同时也带来低推理延迟。

- **随机梯度截断（stochastic gradient truncation）**：每个训练序列随机采样 s 作为最终输出去噪步，只对第 s 步启用梯度，其余步不记录梯度。这样所有中间去噪步都有机会接收监督，同时内存可控。

- **视频级整体分布匹配损失**：不再逐帧计算 MSE，而是把整条生成视频 Xθ 送入 DMD、SiD 或 GAN 目标，直接拉近生成视频分布 pθ(x1:N) 与真实视频分布 pdata(x1:N)。

- **首帧注意力限制**：训练时让模型在去噪当前块时不能看到第一块，以模拟滚动缓存逐出首个 latent 后推理分布，减少 flicker 伪影。

## 4. 核心公式与直觉

**（1）自回归扩散因子分解**

自回归视频扩散模型把联合分布写成：

pθ(x1:N) = ∏_{i=1..N} pθ(xi | x<i)

每个条件 pθ(xi | x<i) 不再是简单的分类分布，而是一个少步扩散过程。某一帧在噪声时间 tj 的 latent 为：

x_i^{t_j} = α_{t_j} x_i + σ_{t_j} ε_i，ε_i ~ N(0, I)

模型 Gθ 从当前噪声帧和过去 KV 预测干净帧 x̂_i^0。直觉是：AR 分解处理“先发生什么、后发生什么”，扩散处理“某个条件帧内部如何从噪声变成清晰图像”。损失目标是让这一串条件生成过程的联合样本分布尽可能接近真实视频样本分布。

**（2）训练目标从逐帧到整体**

传统 TF/DF 的逐帧去噪损失可理解为条件 KL 散度的近似：

E_{x<i ~ pdata} D_KL(pdata(xi | x<i) || pθ(xi | x<i))

上下文 x<i 来自真实数据（DF 中是加噪后的真实数据）。Self Forcing 则优化视频级分布匹配：

min D(pdata(x1:N) || pθ(x1:N))

上下文 x<i 来自模型自己的 rollout 分布 pθ。这个区别是全文最重要的直觉：模型不再只学习“给定完美上下文时如何修一帧”，而是学习“给定自己会犯的错误时，如何让整条视频仍不崩”。DMD 使用反向 KL、SiD 使用 Fisher 散度、GAN 近似 JS 散度，但它们都作用于整条生成视频。

**（3）随机梯度截断的工程直觉**

算法没有对 T 步去噪链完整反传，而是每个序列随机选 s，只让最后一步 j=s 开启梯度。这与公式（2）的分布匹配目标对应：只要 Xθ 是模型推理路径的真实采样，损失就能提供对输出分布的梯度；冻结前置步相当于用 stop-gradient 限制计算图。风险是模型学不到“早期去噪错误如何在后续步被纠正”的长程信号，但换来显存和训练时间上的可行性。

## 5. 训练与推理怎么跑

**训练阶段的一轮 step**

模型初始化不是从零开始。作者先以 Wan2.1-T2V-1.3B 为基座，在 16k 条 ODE 解对上微调因果注意力掩码，得到可用于少步自回归的因果 DiT。随后进入 Self Forcing 后训练。

每个训练迭代按 Algorithm 1 执行：随机采样 s；对 N 个帧或块依次进行自回归 rollout。每个当前帧从纯噪声开始，循环 j=T 到 s；非最后一步只推理并重新注入噪声，不计算梯度；到最后一步开启梯度，输出预测干净帧，追加到 Xθ，再关闭梯度并把当前帧的 KV 嵌入缓存到 KV 中。完成 N 帧后，对整段 Xθ 计算分布匹配损失更新 θ。梯度只经过每个当前帧的最后一步，不流入历史 KV 缓存。

论文实验中使用 4 步扩散；chunk-wise 变体一次生成 3 个 latent 帧，frame-wise 一次生成 1 帧。DMD/SiD 版本不需要真实视频训练数据；GAN 版本使用 14B 基座模型生成 70k 条视频作为训练数据。每个 Self Forcing DMD 实验在 64 张 H100 上约 1.5 小时收敛。Figure 6 显示 Self Forcing 的单迭代训练时间与 TF/DF 相当，同 wall-clock 预算下 VBench 总分更高。原因是 Self Forcing 每帧内部 tokens 仍并行处理，且训练时使用 full attention 和高优化的 FlashAttention-3；TF/DF 则需要专用因果 attention mask 实现，反而有额外开销。

**推理阶段的完整顺序**

推理采用 Algorithm 2 的滚动 KV 缓存。给定目标帧数 M 与缓存长度 L，从空 KV 开始：

1. 对第 i 帧采样纯噪声 latent。
2. 从 j=T 到 j=1 进行少步去噪。每一步都用当前噪声帧和历史 KV 作为条件调用 Gθ。
3. 若 j>1，把预测干净帧 x̂_i^0 经前向过程 Ψ 重新加噪到下一个时间步 t_{j-1}，否则进入下一步。
4. 若 j=1，表示当前帧最终输出；用 GKVθ 计算输出帧的 KV 嵌入。
5. 如果缓存已有 L 帧，先弹出最旧条目，再写入当前条目。

这样每生成一帧新增的计算量只与缓存长度 L 和去噪步数 T 相关，为 O(TL)，不随视频总长度平方增长。论文报告 chunk-wise 版本吞吐 17.0 FPS、首帧延迟 0.69 秒；frame-wise 版本 8.9 FPS、0.45 秒；10 秒视频用滚动缓存生成约 16.1 FPS，而滑动窗口重算 KV 只有 4.6 FPS。

## 6. 实验和消融证明了什么

表 1 和表 2 是主要证据。下面挑出 4 条关键可控结果：

| 证据 | 实验条件 | 核心数字 | 说明 |
|---|---|---|---|
| 主对比 | chunk-wise，4步，DMD | VBench Total 84.31，17 FPS，0.69s | 总分超过 Wan2.1 的 84.26，并大幅优于 CausVid 的 81.20；延迟约 150× 低于 Wan2.1 |
| 消融：训练范式 | 同框架下 chunk-wise | SF-DMD 84.31 vs DF+DMD 82.76 vs TF+DMD 82.32 | DF+DMD 近似复现 CausVid，SF 明显更高 |
| 消融：frame-wise 稳定性 | 从 chunk-wise 改为 frame-wise | SF-DMD 84.26，TF/DF few-step 降到 78.12/80.56 | SF 在更长 AR rollout 下不崩，TF/DF 质量下降明显 |
| 效率与滚动缓存 | 10s video，单 H100 | rolling SF 16.1 FPS；重算 KV 4.6 FPS | 首帧注意力限制训练缓解 naive rolling 的 flicker 伪影 |

最关键的一个消融是：在相同 Wan2.1-1.3B 初始化、相同 4 步扩散、相同 DMD 目标下，DF+DMD 与 TF+DMD 都明显低于 Self Forcing。这说明提升并未来自“少步扩散”或“DMD”本身，而是来自训练时使用自生成上下文和视频级整体监督。另一个关键观察是 SF 从 chunk-wise 转到 frame-wise 时总分几乎不降，而基线下降 2～4 分，这直接支持“曝光偏差被缓解”的结论。

但仍有未被证明的主张：论文承认生成长度显著超过训练上下文时质量仍会下降；梯度截断可能限制长程依赖性；所有实验集中在 Wan2.1-1.3B 这一基座和后训练设置，未提供更大模型规模或不同架构下的验证。VBench 总分与 Wan2.1 只有 0.05 的微弱领先，说明 Self Forcing 的上限目前主要受基座模型能力约束，而不是凭空生产更高质量视频。

## 7. 与前作怎么选

| 方案 | 训练上下文 | 优势 | 主要风险 | 适合场景 |
|---|---|---|---|---|
| Teacher Forcing (TF) | 干净真实历史帧 | 并行训练最简单，监督强 | 推理曝光偏差显著，长视频易崩 | 很短的预测、不需要长 rollout |
| Diffusion Forcing (DF) / CausVid | 带噪真实历史帧 | 覆盖推理时噪声上下文 | 仍非推理真实分布；KV 设计复杂 | 训练时想模拟一定噪声容忍度 |
| Self Forcing | 模型自生成历史帧 | 训练/推理分布一致，适合滚动缓存 | 训练顺序化、显存/梯度截断复杂 | 实时流式、长视频外推、低首帧延迟 |

如果目标是低延迟、因果生成、交互式应用，且已有可少步化的视频扩散基座，优先考虑 Self Forcing。如果应用可以接受慢速双向扩散，并且需要未来帧影响当前帧以获得更强全局一致性，那么 Wan2.1、SkyReels-V2 这类非因果扩散模型仍更合适。如果只有非常有限的 H100 后训练预算，或者无法完成 ODE 初始化和少步微调，TF/DF 仍然是更省工程的替代方案。从论文来看，Self Forcing 是“后训练阶段”的方法，不是直接替代前期数据量巨大的扩散预训练。

## 8. 工程判断与收束

**数据需求**：Self Forcing 的 DMD/SiD 版本在分布匹配阶段是 data-free 的，不需要真实视频数据集；但 ODE 初始化仍需要 16k 条来自基座模型的 ODE 解对，GAN 版本还需要 70k 条 14B 基座生成的视频。论文未披露这些生成数据的具体过滤成本。

**算力与延迟**：单次 SF-DMD 实验约 64 张 H100、1.5 小时收敛。推理在单 H100 上 chunk-wise 17 FPS、0.69 秒，frame-wise 8.9 FPS、0.45 秒。这满足吞吐大于播放帧率且首帧延迟低的条件，但延迟与帧率数字均强烈依赖 Wan2.1-1.3B 的具体实现和 H100 硬件，不能直接迁移到其他设备。

**实现难点**：需要正确实现 KV 缓存与梯度 detach、随机截断点 s、rolling 缓存逐出以及首帧注意力限制。任何一处实现错误都可能导致训练慢、显存爆炸或长视频 flicker。因果 DiT 在训练时使用 full attention 能利用 FlashAttention-3，但在推理时需要专门的 KV 缓存代码路径。

**最可能失败的环节**：如果 ODE 初始化不充分，4 步扩散本身质量不足，Self Forcing 再强也难以挽救基座上限；如果训练上下文长度 N 太小，滚动缓存会很快进入分布外区域，长视频仍可能慢慢退化；GAN 版本若判别器训练不稳定，后训练可能不收敛。梯度截断也可能限制模型学习跨多帧的因果纠错能力。

**指标上限与未回答问题**：当前 VBench 总分没有明显超过 Wan2.1，说明瓶颈主要在基座模型和少步扩散质量。论文未回答：更大的基座模型能否进一步拉开与 TF/DF 的差距？真实交互控制下自回归 rollout 是否比 premature commitment 的 rolling diffusion 更有响应优势？梯度截断在数学上丢失了多少长程信用分配？这些都有待后续验证。

**读完必须记住的 5 件事**

1. Self Forcing 让模型在训练中消费自己生成的过去帧，而不是真实或加噪真实帧，从根本上对齐训练与推理分布。  
2. 视频级整体分布匹配损失取代逐帧 MSE，可搭配 DMD、SiD 或 GAN，且 DMD/SiD 分布匹配阶段不需要真实视频数据。  
3. 少步扩散、随机采样 s、最后一步梯度截断和 KV 梯度 detach 让顺序 rollout 训练在 64 张 H100 上约 1.5 小时即可收敛。  
4. 滚动 KV 缓存配合首帧注意力限制，使长视频外推复杂度为 O(TL)，10 秒生成达到 16.1 FPS，远快于重算 KV 的 4.6 FPS。  
5. 在 Wan2.1-1.3B 基座上，Self Forcing 达到 17 FPS、0.69 秒首帧延迟、VBench 84.31，与更慢双向扩散相当；但超出训练上下文后仍会退化，梯度截断可能限制长程建模。

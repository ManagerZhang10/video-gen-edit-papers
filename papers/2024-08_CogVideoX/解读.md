# 大白话深读《CogVideoX》

## 1. 30 秒定位

CogVideoX 是一个基于扩散 Transformer（Diffusion Transformer, DiT）的文本生成视频模型，由清华与智谱 AI 等团队提出。论文写明它可生成 10 秒、16 fps、最高 768×1360 分辨率的视频，并发布了 5B 与 2B 两个规模，包含文生视频与图生视频版本。核心架构由两部分组成：一个 3D 因果变分自编码器（3D Causal VAE）先把视频在空间和时间上压成潜变量，一个专家 Transformer（Expert Transformer）再把文本嵌入与视频潜变量序列联合建模。为支持长视频和动态语义，论文设计了多分辨率帧打包、渐进分辨率训练和显式均匀时间步采样。需要先明确：这不是摘要或宣传，而是一份架构与训练机制的深读笔记。

## 2. 为什么这篇论文会出现

论文指出，早期文本生成视频模型如 CogVideo 和 Phenaki 展示了 Transformer 预训练的潜力，扩散模型也被用于视频生成。当 DiT 出现后，文生视频进入新阶段，但长期一致性与动态情节仍不清晰。例如提示“一道闪电劈开岩石，一个人从岩石里跳出来”，此前模型难以生成连贯动作。

核心困难有三点。第一，视频在空间与时间上的数据量远大于图像，直接训练高分辨率长视频算力代价高，而如果沿用 2D VAE 逐帧压缩，时间冗余没有被压缩，容易产生闪烁。第二，文本与视频是两种特征空间差异很大的模态，简单拼接后共用 LayerNorm 或注意力，未必能很好对齐语义。第三，互联网视频数据通常缺少准确文本描述，原始视频也包含剪辑、低动态、低质量等噪声，会直接伤害模型对“运动语义”的学习。

此外，论文认为此前常见的分离空间/时间注意力虽然在图像模型微调上便宜，但相邻帧之间的大运动对象难以直接跨帧交互，信息要通过背景补丁隐式传递，增加了学习难度并可能导致不一致。CogVideoX 尝试用 3D 全注意力、3D 因果 VAE 和专家自适应 LayerNorm 分别解决这些问题。

## 3. 方法全景：先看数据流

图 3 展示的整体架构可以简化成如下数据流：

```
输入文本 x_text
      │
      ▼
  T5 编码 ──────────────► z_text
                              │
                              │ 拼接
输入视频 x_video               ▼
      │              [z_text; z_vision] 序列
      ▼                        │
3D Causal VAE encoder          │
      │                        ▼
 latent T×H×W×C       堆叠 Expert Transformer blocks
      │                ├─ Expert AdaLN（按 timestep t 调制）
      ▼                ├─ 3D 全注意力/前馈
  patchify / unfold    └─ 输出序列
      │                        │
      ▼                        ▼
  z_vision              unpatchify 恢复 latent 形状
                               │
                               ▼
                    3D Causal VAE decoder
                               │
                               ▼
                          重构视频
```

下面对每个核心组件拆开说明。

**3D Causal VAE**：输入是原始视频帧，输出是压缩后的潜变量，形状写作 T×H×W×C，分别对应帧数、高、宽、通道数。论文最终采用 8×8×4 压缩比，即空间各压缩 8 倍、时间压缩 4 倍，latent 通道为 16。这个模块由编码器、解码器和 KL 正则器组成，编码与解码对称，中间用 ResNet 阶段交替做下采样与上采样；有些块做 3D 下采样，有些只做 2D 下采样。因果卷积把 padding 放在卷积空间开头，避免未来帧影响当前帧。它的目的不是直接生成最终像素，而是降低视频序列长度、提高重建连续性。

**Patchify**：把 VAE 输出的 T×H×W×C 潜变量按空间 patch 尺寸 p×p、时间 patch 尺寸 q 切成 patch，展平成序列 z_vision。论文给出序列长度为 `T/q · H/p · W/p`，但未在抽取正文中给出具体 p、q 数值。若 q>1，会把第一帧重复到序列开头，用于联合训练图像和视频。

**文本编码**：文本用 T5 编码成 z_text，然后与 z_vision 沿序列维拼接。这个设计让文本 token 和视频 token 进入同一个 Transformer，而不是另作交叉注意力。

**专家 Transformer**：这是论文标题中的核心结构。拼接后的序列进入堆叠 Transformer blocks。与普通 DiT 不同，它用 Expert Adaptive Layernorm（专家自适应 LayerNorm）分别对视觉隐藏状态和文本隐藏状态做调制；调制输入是扩散时间步 t。这样可以分别处理两种模态的特征尺度，又不像 MMDiT 那样用两套独立的 Transformer 参数。注意力部分是 3D 全注意力，文本 token 与所有视频 token 同时计算注意力，视频 token 内部也做空间和时间全注意力。

**重建输出**：Transformer 输出经 unpatchify 恢复潜变量形状，再送入 3D Causal VAE decoder 解码成视频帧。

这个流水线有一个关键假设：VAE 已经学会把视频压缩到具有时间连续性的潜空间；DiT 只需要在这个潜空间上去噪并完成文本条件生成。论文的实验支持该假设，主要来自 VAE 重建指标和生成视频稳定性。

## 4. 核心公式与直觉

论文没有提出很复杂的新公式，核心机制更多是架构与训练策略。理解贡献必需的公式可保留三个。

**公式 1：扩散训练目标**

论文引入 Ho et al. 的简单去噪目标：

\[
L_{simple}(\theta) := \mathbb{E}_{t,x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon, t)\|^2\right]
\]

其中 \(x_0\) 是干净数据（这里对应视频潜变量），\(\epsilon\) 是高斯噪声，\(\bar\alpha_t\) 是噪声调度在时间步 \(t\) 的累积系数，\(\epsilon_\theta\) 是网络预测的噪声。模型看到的是加噪后的潜变量 \(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon\)，目标是还原出加入的噪声。这个公式用于说明时间步采样：\(t\) 理论上在 1 到 T 均匀分布。

不过需要注意，论文在训练设置中实际采用 v-prediction 和 zero SNR，所以部署时模型输出不一定是严格的 \(\epsilon\)，而是 v 参数化形式；论文没有在抽取正文里展开 v-prediction 公式，但它承载同一去噪目标，只是换了参数化来改善低信噪比训练稳定性。

**公式 2：视频潜变量的 patch 序列长度**

\[
L_{z_{vision}} = \frac{T}{q} \cdot \frac{H}{p} \cdot \frac{W}{p}
\]

直觉是：VAE 已经把像素压缩，DiT 还要再把潜变量切块，才能形成 Transformer 可接受的 token 序列。若视频是 10 秒、16 fps，则 T 约 160，经过时间压缩 4 倍后为 40；空间 768×1360 压缩 8 倍后为 96×170，再除以 patch 大小会得到较长序列。这个长度直接决定 3D 全注意力的计算与显存压力。论文因此强调需要 FlashAttention 和长上下文训练经验。

**公式 3：3D-RoPE 的通道分配**

每个视频潜变量 token 有三维坐标 \((x,y,t)\)。论文对每个维度独立施加 1D-RoPE，并在隐藏通道中分配比例：

\[
x:\frac38,\quad y:\frac38,\quad t:\frac28
\]

直觉是空间两个维度信息量相近，合起来占 6/8；时间维度占 2/8。这样做保留了 RoPE 的相对位置建模能力，同时对不同分辨率和时长更灵活。论文在消融中比较了 3D RoPE 与正弦绝对位置编码，显示 RoPE 损失曲线收敛更快。

## 5. 训练与推理怎么跑

### 一轮训练 step

论文的训练由多个模块组成，但一轮 DiT 训练可描述如下：

1. 从数据池采样一个 batch，可能包含不同时长和分辨率的视频，也包含被当作单帧视频的图像。数据经过过滤与 caption 流程已有文本描述。
2. 视频通过已训练的 3D Causal VAE encoder 得到潜变量；文本通过 T5 得到文本嵌入。
3. 潜变量按 patchify 展开为 z_vision，并在需要时重复第一帧以支持图像/视频混合训练；文本嵌入 z_text 与 z_vision 沿序列拼接。
4. 对每个训练样本采样扩散时间步 \(t\)。这里采用 Explicit Uniform Sampling：不是每个 rank 在整个 [1,T] 随机采，而是把 [1,T] 等分成 n 个区间，每个数据并行 rank 在自己的区间内均匀采样，使一个 step 内不同时间步覆盖更均匀。
5. 根据时间步向干净潜变量加噪，得到噪声潜变量。
6. 将拼接序列、时间步 t、3D-RoPE 位置信息送入 Expert Transformer。Expert AdaLN 读取 t，生成调制参数，分别作用于文本隐藏状态和视觉隐藏状态；3D 全注意力在文本和视频 token 上联合计算。
7. 网络输出预测值，按 v-prediction/zero SNR 设置计算损失，优化参数。

论文还写明训练早期先训 VAE，再训 DiT；DiT 采用渐进分辨率训练，先 256px 学习语义与低频信息，再逐步到 512px、768px 学习高频信息。为了在同一 batch 中容纳不同形状的视频，使用 Multi-Resolution Frame Pack，灵感来自 Patch’n Pack，将不同分辨率/时长视频打包成统一 batch 形状。VAE 训练则先 17 帧、256×256，再用上下文并行微调到 161 帧，损失包含 L1、LPIPS、KL，并在几千步后加入 3D 判别器 GAN loss。

### 完整推理顺序

推理阶段与训练不完全相同，大致如下：

1. 用户输入文本，T5 编码为 z_text。
2. 初始化一组噪声潜变量，形状对应目标视频帧数、高度、宽度和 VAE latent 通道。
3. 从高时间步到低时间步逐步去噪。每一步将当前噪声潜变量 patchify 成 z_vision，与 z_text 拼接，加入时间步 t 和 3D-RoPE，送入 Expert Transformer。
4. Transformer 输出经 unpatchify 得到对当前潜变量的更新方向；根据扩散调度器更新潜变量。论文未在抽取正文披露默认推理步数。
5. 去噪完成后的潜变量送入 3D Causal VAE decoder，解码为像素视频。

论文指出不同分辨率推理的时间和空间消耗在附录 A 中给出，但本次抽取没有包含具体数值，因此正文层面无法估算每步延迟。可以确定的是，3D 全注意力的序列长度会随空间分辨率和帧数增长，所以推理显存与计算量会明显高于低分辨率或分离注意力方案。

最关键的一个消融是 Expert AdaLN 对比。理由是：它直接支撑论文标题中的“Expert Transformer”，并且验证了不需要双流 MMDiT 就能处理文本/视频模态差异，显著减少参数量。若这个消融不成立，CogVideoX 的核心架构贡献会被削弱。

需要明确哪些主张尚未被证明。第一，论文在 Figure 2 和结论中说性能随参数、数据、训练量增加而可扩展，但只给出 2B 和 5B 两个模型点，没有拟合 scaling law 或更多规模点，属于趋势性观察，不是严格证明。第二，论文声称视频 captioning 流程“显著提升了生成质量和语义对齐”，但正文没有提供该流程单独关闭后的量化消融，证据主要来自最终模型整体表现，不能把收益精确归因到 captioning。第三，3D 全注意力被证明比 2D+1D 更稳定，但计算成本上限、可扩展到的帧数/分辨率上限没有被量化。第四，论文没有证明更激进的 VAE 压缩比能否同时保持重建质量和训练稳定性，只将其列为 future work。

## 7. 与前作怎么选

这里不列具体产品，而是把 CogVideoX 与两类最接近的架构路线比较：2D VAE + 分离空间/时间注意力，以及 MMDiT 双流结构。

| 方案 | 关键机制 | 何时选 | 何时不选 |
|---|---|---|---|
| 2D VAE + 2D+1D 分离注意力 | 逐帧 2D VAE；空间注意力与时间注意力分离，便于从图像模型微调 | 算力紧张、主要生成短视频或接近静态场景、需要快速继承图像先验 | 需要大运动一致性、长视频或大模型训练稳定性要求高。论文显示早期 FVD 差且易崩溃 |
| MMDiT 双流 | 文本和视觉两套 Transformer 分支，中间通过联合注意力交互 | 模态差异极大，或需要更强解耦的多模态表示 | 参数与算力预算紧；论文认为 Expert AdaLN 用更少参数已能弥合模态差异 |
| CogVideoX：3D Causal VAE + Expert AdaLN + 3D 全注意力 | 视频时空压缩；单序列拼接；用时间步调制分别处理文本/视觉 | 面向长视频、动态动作、文本语义对齐，并且有 FlashAttention 等长序列训练条件 | 资源受限、只需要低分辨率短视频、或团队缺少 3D VAE 训练与上下文并行基础设施 |

简言之，CogVideoX 适合把“运动连贯性”和“语义跟随”作为首要目标的场景；前作或简化路线适合快速实验和低成本部署。选择时要同时考虑 VAE 重建能力和 DiT 序列长度，因为 3D 全注意力的收益伴随更高的计算成本。

## 8. 工程判断与收束

**数据**：论文构建了约 35M 单镜头片段，平均约 6 秒，并额外使用 LAION-5B 和 COYO-700M 中按美学分数过滤出的 2B 图像。数据过滤训练了 6 个基于 Video-LLaMA 的负标签分类器，覆盖剪辑、运动不连贯、低质量、讲座、文本主导、屏幕录制等。captioning 流程先用 Panda70M 生成短描述，再对每帧用 CogVLM 生成稠密图像描述，再经 GPT-4 汇总，最后微调 Llama2 和 CogVLM2-Caption 做大规模视频描述。风险在于过滤与 caption 模型本身会引入语义偏差，论文未给出该环节的单独消融。

**算力/延迟**：论文正文没有给出训练总 GPU 数、训练时长或 FLOPs。推理时间与显存写在附录 A，但本次抽取未包含数值。因此无法根据正文准确估算成本。可以确定的趋势是：3D 全注意力序列长度随帧数和空间分辨率增长，显存与计算需求显著高于分离注意力；VAE 上下文并行只在时间维切分，通信量较小，但仍是长视频训练必要设施。

**实现难点**：Multi-Resolution Frame Pack 要处理同一 batch 内不同时长/分辨率视频的形状一致；3D Causal VAE 的因果 padding 与时间维上下文并行需要正确处理 rank 间发送 temporal kernel size − 1 长度；Explicit Uniform Sampling 需要按数据并行 rank 固定区间；3D-RoPE 要防止不同分辨率时长下位置编码混叠。

**最可能失败的环节**：一是 3D 全注意力在超长视频或超高分辨率下遇到序列长度爆炸，算力与显存不可承受；二是 VAE 压缩比如果再提高，论文已报告收敛困难；三是对高动态视频，自动指标可能奖励静态或低动态样本，导致指标好但语义动态不足；四是数据过滤与 captioning 可能误删有用运动数据或产生错误描述，影响模型学习真实物理动态。

**指标上限与未回答问题**：论文自动指标来自 VBench 等，并非真实物理一致性或因果推理的直接度量；人类评估只与 Kling 对比，范围有限。未回答问题包括：captioning pipeline 的净贡献、VAE 更高压缩比稳定训练的方法、更大规模模型下的 scaling law、3D 全注意力的最大可训练序列长度，以及视频生成中因果性与长期物理一致性的严格评测。

读完必须记住的 5 件事

- CogVideoX 的核心不是单纯扩大 DiT，而是用 3D Causal VAE 先做 8×8×4 时空压缩，再在潜空间用 DiT 去噪生成。
- 文本与视频潜变量被拼成一个序列，送入 Expert Transformer，其中 Expert AdaLN 按扩散时间步分别调制视觉与文本隐藏状态。
- 3D 全注意力替代分离空间/时间注意力，实验支持其对大模型稳定性和 FVD 有帮助，但序列长度和算力成本随之增大。
- 训练稳定性的关键工程包括 Multi-Resolution Frame Pack、渐进分辨率训练、Explicit Uniform Sampling 以及 v-prediction/zero SNR。
- 实验支持其自动指标和人类偏好的整体优势，但 captioning 收益、更高压缩 VAE、scaling law 和长视频上限仍未被严格证明。
